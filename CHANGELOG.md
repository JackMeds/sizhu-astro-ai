# Changelog

All notable user-facing and integration changes should be recorded here. This project is pre-1.0; the current source of truth remains the Git history and tests.

## Unreleased

### Added

- public BaZi, Zi Wei Dou Shu, Da Liu Ren and true-solar-time landing pages;
- bilingual indexable application entries;
- AI discovery page, Agent guide, lightweight `llms.txt` and machine-readable tool registry;
- WebMCP shared browser workspace and static landing-page bootstrap;
- shared `mingxu.*` Agent tool definitions;
- local stdio MCP and stateless Streamable HTTP MCP support;
- boundary-focused guides for day changes, hour branches, solar time, Zi Wei differences and Da Liu Ren transmissions;
- reproducibility Benchmark and open-source trust pages;
- IndexNow notification after successful web deployment;
- GitHub contribution, security and calculation-case workflows.

### Changed

- public product identity standardized on MingXu / 命序; AstroCopy remains the internal calculation-engine identity;
- SEO infrastructure now favors stable canonical URLs, meaningful internal links and Git-derived sitemap dates rather than keyword-generated pages.

### Privacy

- web calculation remains local-first;
- production discovery/analytics infrastructure must not send names, birth/casting inputs, precise location or full chart payloads as telemetry parameters.
