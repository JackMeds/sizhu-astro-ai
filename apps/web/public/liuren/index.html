正时、报数和九宗门不是一回事

正时 / 报数 / 指定占时负责确定最终占时；得到占时后，程序统一进入同一套排课算法。九宗门则是四课生成之后用于判断三传的传统取传规则。把这两层分开，才能避免“起课方式”和“取传方法”混在一起。

为什么要做多引擎校验？

六壬实现之间在贵人法、昼夜界定、月将边界和部分课体细节上可能出现差异。本站保留自己的可审计结构层，同时用固定版本的完整 TypeScript 引擎比对重叠字段，并在持续集成中保留固定 Python 课例作为参考。出现差异时不会静默隐藏。

建议写清楚占问，因为 AI 解课时需要知道你关注的事件范围；不过程序本身也允许先生成课盘，再补充具体问题。

报数起课是另一套六壬算法吗？

不是。报数只负责把一个正整数循环映射到十二地支中的最终占时，之后仍然使用同一套天地盘、四课和三传算法。

本站会直接下吉凶结论吗？

网页负责把课盘算出来并整理成结构化资料，不在站内直接给出命理解读。这样可以把“排课事实”和“模型解释”分开，也方便你选择不同 AI 比较分析。
