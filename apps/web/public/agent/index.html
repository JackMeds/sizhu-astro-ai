MingXu · AI Agent Interface

命序 MingXu：让 AI 调用确定性的术数计算。

命序 MingXu 是一个确定性优先的八字、紫微斗数、真太阳时、运限和大六壬计算工具，同时提供 WebMCP 与 MCP Agent 接口。程序先生成可复核的结构，AI 再负责解释。

Capabilities

BaZi / 八字四柱十神、藏干、纳音、空亡与五行结构 Luck cycles / 运限大运、流年、流月与多日期比较 Zi Wei Dou Shu / 紫微斗数十二宫、主星、四化、大限与动态范围 True Solar Time / 真太阳时经度修正、均时差、跨时辰与跨日期 Da Liu Ren / 大六壬天地盘、天将、四课、三传、旬空与交叉校验
Structured outputJSON、Markdown、纯文本和 warning / evidence

AI 使用原则

  1. Compute first, interpret second. 先调用命序工具生成四柱、宫位、运限或课盘，再进入解释。
  2. 保留 IANA 时区、标准时间、太阳时修正、有效时间以及跨时辰/跨日期提醒。
  3. 把结构事实、传统规则和综合解释分开；不要把五行计数当作旺衰结论。
  4. 不要为了符合叙事而自行重排四柱、紫微宫位或大六壬三传；warning 和引擎差异不可丢弃。
