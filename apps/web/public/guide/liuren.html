大六壬怎么起课：先分清“起课入口”和“九宗门”

大六壬里经常把“怎么起课”和“怎么取三传”混在一起说。本站把这两层拆开：起课入口只负责确定最终占时；得到占时后，不管入口是什么，都进入同一套月将、天地盘、天将、四课与三传算法。

本站支持三种起课入口

正时起课

直接使用实际起课时间。可选择标准时、地方平太阳时或视太阳时（真太阳时）。

报数起课

把用户报出的正整数按十二地支循环映射：1=子、2=丑……12=亥、13重新回到子。例如 26 → 丑。

指定占时

高级/复盘入口：直接指定子至亥其中一个占时支，基础日期仍用于确定日干支、月将等历法信息。

报数不是另一套天地盘或三传算法。它只是换一种方式得到“最终占时支”；随后仍进入同一套六壬排课。

九宗门是什么？

九宗门是传统大六壬中从四课判定初传、进而确定三传的一组取传规则。常见归纳包括：贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、返吟。程序先生成四课，再按条件选择实际命中的取传法，而不是让用户在九个按钮里随意挑一个。

起课入口（正时 / 报数 / 指定占时） ↓ 最终占时 + 日干支 + 月将 ↓ 天地盘 ↓ 十二天将 ↓ 四课 ↓ 九宗门条件判定 ↓ 初传 → 中传 → 末传 ↓ 旬空 / 遁干 / 六亲 / 课体 / 神煞 evidence ↓ 结构化 JSON → 复制给你喜欢的 AI 解课

完整结果现在包含什么

  • 节气、月将、日时干支与最终占时
  • 天地盘、十二天将、贵人起点与昼夜信息
  • 四课的上下神、天将与生克关系
  • 三传、实际取传法、传局
  • 旬空、三传遁干、六亲
  • 课体 / 格局标签
  • 带来源信息的传统神煞 evidence
  • 多引擎重叠字段校验与版本 manifest

为什么要多引擎校验

六壬实现之间在贵人法、昼夜界定、月将边界和部分课体细节上可能存在口径差异。本站自己的 sizhu-liuren-ts 保留可审计结构层，同时使用固定版本的完整 TypeScript 引擎做重叠字段比较，并在 CI 中继续运行固定 kinliuren Python 课例。差异不会被静默吞掉，而会写进导出结果。

为什么本站不直接“解课”

本站目标是把“排课事实”做成稳定输入，而不是绑定某个模型。生成完整课盘后，可以点击“复制给 AI”，把结构交给 ChatGPT、Claude、DeepSeek、Kimi 或其他你喜欢的模型。提示词会要求模型不要自行重排，并先区分程序事实、传统规则与综合解释。
