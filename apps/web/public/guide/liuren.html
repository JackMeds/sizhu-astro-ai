大六壬排盘 Beta：先把结构算对，再谈三传与解课

本站把大六壬作为独立的起课 session，而不是出生八字的一部分。用户只需要输入起课时间；程序会先统一时间口径，再生成六壬引擎需要的节气、农历月、日干支与时干支。

当前已经公开并做回归验证的结构
  • 月将
  • 天地盘
  • 天将
  • 四课

为什么标 Beta？

因为完整大六壬还需要三传、课体以及部分神煞等结构。当前项目选择逐模块移植：每完成一块 TypeScript 算法，就与固定的 Python 参考引擎逐字段对照；未验证的部分不会在网页上伪装成完整结果。

参考引擎怎么固定？

迁移使用 kentang2017/kinliuren 的固定 source commit 作为 CI oracle。固定 commit 的可执行 Liuren.result(0) 是迁移回归真值；如果 README prose 与实际函数输出矛盾，两者会被记录为上游差异，而不会混为同一事实。

当前计算链

起课时间 → 标准时/太阳时口径 → 节气与农历月 → 日时干支 → 月将 → 天地盘 → 天将 → 四课

当前页面不提供六壬解课。三传与课体尚未完成前，导出的 Beta JSON 也不应被当作完整六壬课。

后续顺序

下一步会继续迁移三传与课体，再追踪神煞在上游项目中的真实来源。完成后，六壬结果同样可以复制到你喜欢的 AI 进行分析，而本站保持“只计算、不解读”的产品边界。
