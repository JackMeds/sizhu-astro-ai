四柱星盘 AI / 指南 / Agent / MCP

让 AI 直接调用八字、紫微和大六壬计算

如果你只是普通用户，网页里的“复制给 AI”已经够用。如果你使用 Codex、Claude Desktop、Cursor 或其他支持 MCP / Agent 工具调用的客户端，可以直接把本站的确定性计算能力接进去，让 AI 先调用工具排盘，再进行解释。

先分清三种接入方式

网页 WebMCP

网页本身通过 document.modelContext（并兼容部分 navigator.modelContext 实现）注册 sizhu.* 工具。支持该能力的浏览器 / Agent 打开网站即可发现工具。

本地 MCP

apps/mcp 是标准 stdio MCP Server。适合 Codex、Claude Desktop、Cursor 等能够启动本地 MCP 进程的客户端。

Remote MCP

公开的 HTTP / Remote MCP endpoint 目前还没有上线。不要把 GitHub Pages 网站地址误当成 Remote MCP URL。

WebMCP 目前仍属于实验性的网页 Agent 接口。没有检测到 WebMCP 时，本站网页仍然可以正常排盘；需要稳定 Agent 接入时优先使用本地 stdio MCP。

Codex：两步接入

需要 Git、Node.js / npm，以及已经安装好的 Codex。下面命令会把项目固定放到用户目录，方便后续更新。

1. 安装 / 更新并构建 MCP

$dir="$env:LOCALAPPDATA\sizhu-astro-ai"; if (Test-Path "$dir\.git") { git -C $dir pull --ff-only } else { git clone https://github.com/JackMeds/sizhu-astro-ai.git $dir }; npm --prefix $dir install; npm --prefix $dir run build:mcp

2. 注册到 Codex

codex mcp add sizhu -- npm --prefix "$env:LOCALAPPDATA\sizhu-astro-ai" run start:mcp

1. 安装 / 更新并构建 MCP

DIR="$HOME/.local/share/sizhu-astro-ai"; if [ -d "$DIR/.git" ]; then git -C "$DIR" pull --ff-only; else git clone https://github.com/JackMeds/sizhu-astro-ai.git "$DIR"; fi; npm --prefix "$DIR" install && npm --prefix "$DIR" run build:mcp

2. 注册到 Codex

codex mcp add sizhu -- npm --prefix "$HOME/.local/share/sizhu-astro-ai" run start:mcp

注册后，在 Codex 中使用 /mcp 查看已连接的服务器和工具。

通用 stdio MCP 配置

先运行上面的安装命令，然后在支持 mcpServers 风格配置的客户端中加入下面的配置。把路径替换成你机器上的绝对路径。

{ "mcpServers": { "sizhu": { "command": "npm", "args": [ "--prefix", "/ABSOLUTE/PATH/TO/sizhu-astro-ai", "run", "start:mcp" ] } } }

WebMCP：网页直接注册的工具

网站打开后，如果当前浏览器 / Agent 支持 WebMCP，会注册这些主要入口：

sizhu.aboutsizhu.create_profilesizhu.create_ai_promptsizhu.get_transit_snapshotsizhu.create_liuren_chartsizhu.create_liuren_base_chartsizhu.get_current_chart

这些工具直接复用网页的本地计算逻辑。出生资料、起课输入和提示词生成不需要先上传到本站服务器。

Agent 应该怎么使用这些工具

  1. 先调用程序工具排盘，不让模型手算四柱、紫微运限或六壬三传。
  2. 检查 warnings、时间口径和六壬 crossCheck。
  3. 区分程序计算事实、传统规则与综合解释。
  4. 需要完整方法边界时，让 Agent 阅读 agents.md。
