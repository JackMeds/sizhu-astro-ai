AstroCopy · Privacy

Local computation, explicit sharing.

AstroCopy computes birth charts and Da Liu Ren structures in the browser. It does not automatically send birth or casting data to an external AI service.

Data kept in the browser

Birth-input drafts, generated chart history, selected views, comparison dates, and interface preferences may be stored in browser storage on the current device. AstroCopy does not require an account and does not provide automatic cloud synchronization.

WebMCP and AI tools

When a person explicitly invokes a WebMCP tool, the tool may return chart inputs, computed structures, selected dates, warnings, or current workspace state to the active Agent. That returned data is then processed under the Agent provider's terms. “Local-first” does not mean that data explicitly shared with an Agent remains only inside the browser.

Copying and opening another AI

Copy buttons place the selected structured package on the clipboard. Quick links to ChatGPT, Claude, Gemini, DeepSeek, Kimi, or another service only open that service; AstroCopy does not automatically paste or transmit the clipboard contents.

Analytics

The public site may use privacy-oriented aggregate page and performance analytics. Chart inputs, birth data, generated chart JSON, casting questions, and clipboard contents are not intentionally included in those analytics events.

Deletion

Use the history controls in the application to remove saved charts, or clear site data for astrocopy.jackmeds.top in the browser. Because AstroCopy does not maintain a user account database for these charts, there is no separate server-side chart account to delete.

Traditional-metaphysics boundary

AstroCopy is a cultural research and calculation tool. Traditional interpretations are not modern scientific conclusions and do not replace medical, legal, financial, safety, or other professional advice.

AstroCopy · 隐私说明

本地计算，主动分享。

AstroCopy 在浏览器内计算出生命盘和大六壬结构，不会自动把出生资料或占问内容发送给第三方 AI。

保存在浏览器里的数据

出生资料草稿、命盘历史、当前视图、比较日期和界面偏好可能保存在当前设备的浏览器存储中。项目不要求登录，也不会自动进行云端同步。

WebMCP 与 Agent

当用户主动调用 WebMCP 工具时，工具可能把输入资料、程序计算结构、目标日期、警告或当前工作区状态返回给正在使用的 Agent。之后这些数据将按照对应 Agent 服务的条款处理。“本地优先”并不表示主动交给 Agent 的数据仍然只留在浏览器中。

复制与打开第三方 AI

复制按钮只会把所选结构化资料写入剪贴板。ChatGPT、Claude、Gemini、DeepSeek、Kimi 等快捷链接只负责打开对应网站；AstroCopy 不会自动粘贴或发送剪贴板内容。

统计与删除

公开网站可能使用隐私友好的汇总访问与性能统计，但不会有意把出生资料、命盘 JSON、占问内容或剪贴板内容放入统计事件。用户可以在网页历史控件中删除命盘，也可以清除浏览器中该站点的数据。
