Free · Open Source · Local First

基础排盘不需要被锁在付费墙后，也不需要绑定某一家 AI。

命序把八字、紫微斗数、大六壬、运限和真太阳时计算做成公开、可检查的程序。网页基础功能免费、无需注册，源码以 GPL-3.0 发布；你可以直接使用网页，也可以审查代码、自己部署或通过 MCP 接入 AI Agent。

免费具体意味着什么？

  • 核心排盘和结构化导出不要求购买会员。
  • 不要求注册账号才能生成命盘或课盘。
  • 不会因为用户选择 ChatGPT、Claude、Gemini、DeepSeek、Kimi 或本地模型而锁定功能。
  • 开源许可允许在 GPL-3.0 条款下研究、修改和再分发代码。

为什么开源很重要？

历法边界、真太阳时、换日、紫微宫位和大六壬三传都可能因为实现口径不同产生差异。公开源码意味着计算链、依赖版本、测试和已知差异都可以被复核，而不是只能相信网页最终显示的结果。

隐私边界

网页主要在当前浏览器中计算和保存草稿/历史记录。命序不会自动把出生资料发送给外部 AI；只有当用户主动调用 Agent 工具、复制导出或把内容发送给第三方服务时，相应数据才进入该服务的处理范围。

开发者与 AI Agent

同一套确定性计算核心同时服务网页、WebMCP 和 MCP。浏览器 Agent 可以操作可见工作区；Remote MCP 则面向支持 MCP 的客户端提供无状态计算能力。

怎样贡献？

最有价值的贡献通常不是“再加一个解释结论”，而是提供可复现边界案例、补充测试、修正文档、增加语言支持或指出两个实现之间的具体差异。提交计算问题时，请尽量提供明确的日期、时间、时区、经度、换日/真太阳时口径、软件版本和预期结果来源。

先验证，再传播

如果你想判断项目是否值得信任，建议先看公开 Benchmark 和测试源码，而不是只看宣传文案。
