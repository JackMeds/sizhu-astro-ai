# AstroCopy — Agent Guide

AstroCopy is a deterministic, local-first BaZi, Zi Wei Dou Shu, transit, apparent-solar-time, and Da Liu Ren workspace.

Treat AstroCopy as a **calculation substrate and shared browser workspace**, not as a free-form fortune-telling prompt.

## Operating principles

1. **Compute first, interpret second.** Pillars, luck cycles, annual/monthly transits, Zi Wei scopes, and Da Liu Ren structures should come from AstroCopy tools.
2. **Use explicit time semantics.** Preserve the IANA time zone, civil time, longitude correction, equation of time, effective time, and any branch/date boundary change.
3. **Structural facts precede interpretation.** `bazi.facts` can establish encoded combinations, clashes, harms, breaks, punishments, Fu Yin, and Three-Harmony / Three-Meeting candidates. It does not establish fortune or a successful transformation.
4. **Respect rule gates.** A traditional source enters evidence only when its encoded conditions match. Similar words are not a rule match.
5. **Do not equate Five-Phase counts with strength.** `elementCounts` is a structural display, not a final Day-Master strength judgment.
6. **Preserve uncertainty and warnings.** Surface missing longitude, time corrections crossing an hour branch or date, engine differences, and school-specific assumptions.
7. **Never modify computed facts to fit a story.** Do not recalculate or rewrite the Four Pillars, Zi Wei palaces, or Da Liu Ren transmissions from memory.
8. **Check Da Liu Ren cross-validation first.** When `crossCheck.status` is not `matched`, explain `crossCheck.differences` before interpretation.
9. **Keep traditional metaphysics in its proper frame.** It is a cultural interpretive system, not modern scientific prediction and not a substitute for professional advice.

## Shared WebMCP workspace

WebMCP tools modify the same visible state used by the person in the page. After an action, describe the visible change briefly and let the user inspect or undo it.

### `astrocopy.create_birth_chart`

Create a deterministic BaZi and Zi Wei profile and show it in the current workspace.

Required information:

- birth date and local wall-clock time;
- gender input used by the underlying engines;
- IANA time zone;
- calendar type;
- solar-time mode;
- longitude when solar-time correction is requested;
- sect when the user has a specific midnight convention.

After execution:

- the chart appears in the page;
- the workspace opens an appropriate result view;
- an Agent activity entry is added;
- warnings remain visible.

### `astrocopy.inspect_chart`

Open and focus one of the visible chart views, such as:

- overview;
- BaZi;
- Zi Wei;
- transits;
- calculation audit.

Use this instead of merely claiming to have changed the page.

To open Zi Wei and visibly emphasize the semantic Life and Body Palace targets:

```json
{
  "view": "ziwei",
  "focusIds": ["ziwei-palace-life", "ziwei-palace-body"]
}
```

### `astrocopy.inspect_transit`

Select a target solar date in the shared transit workspace. Use the result generated by AstroCopy rather than calculating luck-cycle or Zi Wei dynamic scopes from memory.

### `astrocopy.compare_transits`

Compare two to five target dates. The page creates a visible comparison workspace. Keep the set small and directly related to the user's question.

```json
{
  "targetDates": ["2027-06-15", "2029-06-15", "2032-06-15"]
}
```

### `astrocopy.get_workspace_state`

Read the current state selected by the person or Agent, including the active view, selected transit, comparison set, current profile status, warnings, and recent activity.

Use this before continuing a multi-step workflow when the user may have changed the page manually.

## Canonical profile

The core TypeScript API is:

```ts
createAstroProfile(input)
```

It returns:

- `input`: normalized input;
- `time`: civil, local-mean-solar, apparent-solar, and effective time semantics;
- `bazi`: pillars, Ten Gods, hidden stems, Na Yin, void branches, luck cycles, annual/monthly data, and deterministic relation facts;
- `ziwei`: normalized palaces, stars, transformations, decadal ranges, and calculation metadata;
- `ai`: concise summary and evidence blocks;
- `warnings`: uncertainties that must not be discarded;
- `raw`: audit evidence and engine-specific material.

## Transit snapshot

```ts
createTransitSnapshot(input, "2029-06-15")
```

The result combines:

- the matching BaZi 10-year cycle and annual transit;
- deterministic relations involving the natal chart, cycle, and year;
- Zi Wei decadal, nominal-age, annual, monthly, daily, and hourly scopes.

## Complete Da Liu Ren

Da Liu Ren is an independent divination session, not part of a natal profile.

### Casting entry and transmission rule are different layers

Supported entries:

- `castingMethod: "time"`: use the actual casting time;
- `castingMethod: "number"`: map a positive number cyclically with 1=Zi through 12=Hai;
- `castingMethod: "branch"`: choose an hour branch directly.

The Nine-School methods determine the Three Transmissions from the Four Lessons. They are not nine user-selectable casting modes.

```ts
createCompleteLiurenChart({
  dateTime: "2026-08-15T09:30:00-07:00",
  timezone: "America/Los_Angeles",
  castingMethod: "time",
  question: "Optional concrete question"
})
```

The normalized result includes:

- Month General;
- Earth and Heaven plates;
- Twelve Generals and Nobleman/day-night data;
- Four Lessons;
- Three Transmissions and the selected rule;
- void branches;
- hidden stems and Six Relations;
- transmission pattern and chart-form tags;
- source-gated Shen-Sha evidence;
- engine manifest, warnings, and overlap checks.

### Da Liu Ren validation

- `sizhu-liuren-ts@0.2.0`: AstroCopy's auditable native structure layer;
- `mingyu-core@0.1.23`: complete TypeScript engine and second implementation;
- pinned `kentang2017/kinliuren` commit `3ba45a9540f08269b56d81508a061c7d46938785`: executable Python CI oracle.

When overlap checks differ, do not hide or smooth over the disagreement.

## Recommended workflow

For a natal or transit question:

1. Read the current workspace state.
2. Reuse the existing profile when the inputs match.
3. Otherwise collect the minimum missing birth/time-zone data and create the chart.
4. Check warnings and time boundary changes.
5. Open the relevant visible view.
6. Select or compare the requested dates.
7. Explain program facts first, then traditional rules, then synthesis.
8. State uncertainty and ask for real-world context before strong advice.

For a Da Liu Ren question:

1. Establish the casting entry: time, number, or branch.
2. Collect the time zone and longitude only when applicable.
3. Create the complete chart.
4. Inspect cross-check status and warnings.
5. Read the Four Lessons, Three Transmissions, rule, void branches, hidden stems, Six Relations, patterns, and gated Shen-Sha.
6. Interpret only when requested, without recalculating the structure.

## Privacy

AstroCopy computes in the browser and does not automatically send birth or casting data to an external AI.

When a user invokes a WebMCP tool, the tool result is available to the current Agent and is processed under that Agent service's terms. Do not imply that Agent-visible data remains solely inside the local browser.
